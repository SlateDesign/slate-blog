## About Slate Blog

Slate Blog is an open-source, minimalist blog theme built with Astro, React, TypeScript, and Tailwind CSS. It is designed for publishing notes and articles with a fast, focused reading experience.

The theme supports Markdown and MDX posts, responsive layouts, light and dark modes, syntax highlighting, math, RSS, search, tags, related posts, and accessible desktop and mobile navigation.
