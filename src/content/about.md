## About Slate Blog

Slate Blog is an open-source, minimalist blog theme built with Astro, React, TypeScript, and Tailwind CSS. It is designed for publishing notes and articles with a fast, focused reading experience.

The theme supports Markdown and MDX posts, responsive layouts, light and dark modes, syntax highlighting, math, RSS, search, tags, related posts, and accessible desktop and mobile navigation.

## Project principles

- Keep the interface quiet and let the content lead.
- Generate fast static pages with minimal client-side JavaScript.
- Make writing workflows work naturally with Markdown and Obsidian.
- Provide useful reading tools without turning the theme into a complex publishing system.
- Keep optional features explicit, configurable, and easy to remove.

Slate Blog is available on [GitHub](https://github.com/SlateDesign/slate-blog). Edit this file to adapt the page to a specific site, or delete `src/content/about.md` to remove the About navigation, route, and sitemap entry.
